# محرر الفيديو (المرحلة 1)

## كيف تحصل على ملف APK
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد كما هي (مع مجلد `.github`).
2. افتح تبويب **Actions** ثم **Build APK** ثم **Run workflow** (يعمل تلقائياً أيضاً عند كل رفع).
3. بعد انتهاء البناء افتح التشغيلة، ومن **Artifacts** حمّل `video-editor-apk`.
4. فك الضغط وثبّت `app-release.apk` على هاتفك.

إذا فشل البناء، انسخ لي آخر 30 سطراً من سجل الخطوة الحمراء وأصلحه.
